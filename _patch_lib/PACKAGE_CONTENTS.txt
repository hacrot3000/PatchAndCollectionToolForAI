Python Patch Tool v6.9.3 — selector redraw and local queue-concurrency regression repair

Public entry point:
  tools/run_python_patches.sh

MANDATORY COLLECT public contract:
  AI delivers one ZIP containing exactly one CODE_COLLECTION_REQUEST*.json.
  User puts that ZIP in patchs/ and runs only ./tools/run_python_patches.sh.
  Loose request JSON and manual COLLECT-subcommand guidance are obsolete/invalid.
  Successful COLLECT prints exactly one highlighted [PRIMARY - UPLOAD THIS FILE]
  result ZIP path after existence/location/ZIP-CRC verification.
  A COLLECT rc=0 is accepted only after the request ZIP is archived from
  patchs/ to patchs/patched/.

LOCAL DUPLICATE PATCH contract retained from v6.8.x:
  Normal zero-argument queue compares runnable PATCH packages only with this
  project's local patchs/patched/ files. Exact SHA-256 content identity is used.
  No PROJECT KEY, network, remote/shared history, or other-machine state is read.
  Identical renamed packages are skipped; same-name packages with changed bytes
  remain runnable. Duplicate queue files are not deleted or moved. They are
  reported as [SKIPPED:DUPLICATE_LOCAL] with the local matched history path.

Compatibility requirement:
  Existing private core modules such as python_patch_runner.py and the readonly
  collector must already be installed. They are deliberately not reconstructed
  from incomplete evidence. The public launcher keeps PATCH execution in-place
  with --transaction off; SANDBOX/worktree remains removed.

Release scope:
  Retains the v6.9.x selector-priority/duplicate/COLLECT behavior and fixes only
  regressions: height/width-safe fullscreen redraw, symlink/hardlink-safe local
  queue locking, and COLLECT signal cleanup during post-exit drain. No unrelated
  feature group is started.

Retained duplicate hardening from v6.8.x:
  Symlinked/shared patchs or patchs/patched history is never authoritative for
  local duplicate suppression. Selected PATCHes are rechecked immediately
  before launch so an identical PATCH archived moments earlier is skipped.

Retained V6.9.0 selector priority contract:
  In the TTY selector, Space keeps normal [x] selection. Keys 0..9 assign an
  explicit priority to the current row. Numbered rows execute first from low to
  high; equal numbers preserve the tool's displayed natural order. Remaining
  [x] rows execute afterwards in natural order. Line-mode numeric item indexes
  remain unchanged for backward compatibility.


V6.9.3 in-place boundary hardening:
  Historical/short PATCH execution flags such as `-a -y --move` are treated as
  execution-capable and receive `--transaction off`. Only documented read-only
  utility routes (`paths`, help, version) bypass the execution-only argument.

V6.9.3 packaging invariant:
  tools/run_python_patches.sh is shipped executable (Unix mode 0755); clean-unzip tests enforce it.

V6.9.3 additional invariants:
  Fullscreen queue frames never exceed terminal_height-1 rows; long queues use
  a display-only viewport. Queue locking never follows symlink/multi-hardlink
  lock state or truncates lock files. COLLECT signal forwarding remains active
  through post-exit stdout drain so descendants cannot be orphaned.
