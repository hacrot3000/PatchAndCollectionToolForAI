Normal use:
  unzip -o python_patch_tool_v6.11.0.zip -d PROJECT_ROOT
  ./tools/run_python_patches.sh

The overlay natively supports pack-only COLLECT requests for exact current files.
Other COLLECT actions are delegated to the installed private collector core and remain revision-specific.
The overlay does not reconstruct or replace missing/private PATCH runner core modules.

COLLECT request ZIP artifact: CODE_COLLECTION_REQUEST_<purpose>_<timestamp>.zip
