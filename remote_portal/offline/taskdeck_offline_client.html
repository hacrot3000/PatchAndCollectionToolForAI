TaskDeck — Ghép đôi an toàn

Client OFFLINE, chưa hỗ trợ điều khiển Remote. Chỉ dùng tệp này đã tải xuống khi PHP còn đáng tin cậy. Luôn mở tệp HTML lưu trên máy; không mở bản HTML mới từ PHP sau khi đã ghép đôi.

1. Sinh khóa client

Chọn tài khoản TaskDeck cục bộ trên host. Khóa bí mật chỉ tạo trong Firefox và chỉ được xuất ra trong kho khóa đã mã hóa.

Public key client để nhập vào lệnh taskdeck remote-key --workspace /duong/dan/project add <username> <public-key>

Chưa tạo

2. Ghim public key Agent từ host

Trên host chạy taskdeck remote-key --workspace /duong/dan/project host-key. Sao chép Agent public key (Ed25519, Base64) hiển thị trực tiếp trên host; không lấy từ PHP.

Chưa nhập

3. Lưu kho khóa mã hóa

Chỉ thực hiện sau khi khóa client đã được host duyệt và public key Agent đã đối chiếu. Chọn một mật khẩu bảo vệ kho khóa khác mật khẩu Portal và TaskDeck; cần giữ tệp JSON lẫn mật khẩu này.

4. Kiểm tra mở khóa (khi sử dụng lại)

Mở lại chính tệp HTML đáng tin cậy này bằng Firefox, chọn kho khóa JSON, nhập mật khẩu bảo vệ để kiểm tra chữ ký và khóa Agent đã ghim. Đây là kiểm tra cục bộ; không kết nối PHP.

Không có kết nối mạng. Remote Control đang bị khóa.
